# Тест: скрытие сезона без игр (staging)

Файлы с суффиксом **`-staging`** не трогают боевой сайт. На бою остаются `games-hub.js` и `seasons-config.js` без изменений.

## Что делает тестовая версия

Если на главной **нет ни одной сезонной игры** (по правилам из `seasons-config-staging.js`):

- скрывается вкладка **«Сезон»** в блоке анонсов;
- скрывается панель `#kv-panel-season`;
- скрывается блок **«Календарь сезона»** (`.kv-season-block`, таблица в `#divCalendar2`);
- скрывается полоска `#kvHero`, если она есть в разметке.

Если сезонные игры появятся — всё снова показывается.

## Файлы для загрузки на тестовый домен

| Файл | Действие |
|------|----------|
| `seasons-config-staging.js` | Загрузить (копия конфига сезона) |
| `games-hub-staging.js` | Загрузить (логика с скрытием) |
| `kovrov-games-hub-staging.css` | Загрузить (страховка для CSS) |
| `editor-top-full-staging.html` | Вставить в «Верхнюю часть» **только на тесте** |

Остальные CSS/JS (`kovrov-global.css`, `kovrov-mobile.css`, tab bar и т.д.) — как на бою, без `-staging`.

В `editor-top-full-staging.html` замените `144762` на **ваш** ID загрузки.

## Как проверить скрытие

1. В `seasons-config-staging.js` на компьютере временно сделайте пустыми `match.gids` и `match.titleContains`.
2. Перезалейте файл на тестовый домен.
3. Ctrl+F5 на главной — вкладки и календарь сезона должны исчезнуть.
4. Верните настройки сезона и перезалейте снова — блоки должны появиться.

## После успешного теста

Напишите — подготовим **финальные** файлы без `-staging` для боевого сайта (`games-hub.js`, при необходимости CSS).
