# design-EN — файлы для Encounter (Ковров)

Репозиторий содержит **только** то, что нужно залить на сайт или вставить в **редактор дизайна** домена. Локальные прототипы, старые черновики и служебные файлы здесь не хранятся.

**ID закачки в примерах:** `144762` — замените на свой в URL, если загружаете с другого аккаунта (`https://d1.endata.cx/images/personal/ВАШ_ID/…`).

---

## Два варианта внедрения

| Вариант | Когда | CSS/JS на сервер | Редактор |
|--------|--------|------------------|----------|
| **A. Только блок игр** | Уже есть шапка kovrov, нужны вкладки и карточки | 3 файла | `editor-top-snippet.html` + `editor-main-home-snippet.html` |
| **B. Полный дизайн** | Тест/боевой как 126.en.cx: шапка, меню, спонсоры, мобила | 7 файлов | `editor-top-full-test111.html` + остальные `editor-*-test111.html` |

Штатные блоки `#boxCenterActiveGames` и `#boxCenterComingGames` на главной **не удалять** — `games-hub.js` читает их и скрывает после отрисовки.

## Файлы для закачки на Encounter

Админка домена → **закачка файла** → скопировать URL каждого файла.

| Файл | Назначение | Где подключается |
|------|------------|------------------|
| `seasons-config.js` | Сезон: `activeSeasonId`, список `gid`, фраза в названии, ссылки на регламент и таблицу | Скрипт в «Верхней части» (см. сниппеты) |
| `games-hub.js` | Парсит таблицы игр EN, рисует `#kvGamesHub`, вкладки, карточки; скрывает старые списки | После `seasons-config.js`, после jQuery |
| `kovrov-games-hub.css` | Стили хаба игр, календарей, мобильный блок в конце; скрывает `#boxComingGames` в левой колонке | `<link>` в «Верхней части» |
| `kovrov-global.css` | **Вариант B:** основной глобальный скин (фон, шапка, меню, колонки) | `<link>` в «Верхней части» |
| `kovrov-mobile.css` | **Вариант B:** доп. правила мобильной шапки и вёрстки | После `kovrov-global.css` |
| `kovrov-responsive.css` | **Вариант B:** адаптив без классов на `body` (внутренние страницы, FAQ, регламенты) | Последним из CSS |
| `kovrov-inner-pages.css` | **Вариант B:** EnMail, послужной список, страницы команды/игрока | Вместе с global |
| `kovrov-team-service-record.js` | **Вариант B:** послужной список — убрать «Загрузка…», сворачивание `>>` | В конце «Верхней части», после `games-hub.js` |

### Вариант A — закачать 3 файла

`seasons-config.js`, `games-hub.js`, `kovrov-games-hub.css`

### Вариант B — закачать 7 файлов

Все из таблицы выше, кроме устаревшего `kovrov-theme-test.css` (не использовать).

**Порядок `<link>` в шапке (вариант B):**  
`kovrov_css.css` (уже на сервере) → `kovrov-games-hub.css` → `kovrov-global.css` → `kovrov-mobile.css` → `kovrov-responsive.css` → `kovrov-inner-pages.css`

**Порядок `<script>`:** `seasons-config.js` → `games-hub.js` → `kovrov-team-service-record.js`

## Файлы для редактора дизайна

Режим **«HTML код»** (не «Визуально»), иначе редактор удалит пустые `<ul id="kv-grid-…">`.

| Файл | Вкладка редактора | Действие |
|------|-------------------|----------|
| `editor-top-snippet.html` | **Верхняя часть** | **Вариант A:** вставить **в конец**, не удаляя существующие `link`/`script` (шапка, `kovrov_css.css`, онлайн). Три строки: CSS хаба + 2 скрипта. |
| `editor-main-home-snippet.html` | **Верхняя область на главной** | **Вариант A:** вставить `#kvHero` и `#kvGamesHub` с пустыми списками. Календари `#divCalendar` не трогать — оставить в центральном контенте. |
| `editor-top-full-test111.html` | **Верхняя часть** | **Вариант B:** полная шапка `dnk_head`, меню, inline-стили мобилы, все CSS/JS. Заменить содержимое вкладки или аккуратно слить с боевым. Убрать старую ссылку на `kovrov-theme-test.css`, если была. |
| `editor-main-home-FIX-test111.html` | **Верхняя область на главной** | **Вариант B:** разметка главной с сетками для `games-hub.js`. Использовать, если после «Визуально» пропали `kv-grid-*`. |
| `editor-right-test111.html` | **Правая часть** | **Вариант B:** соцсети + спонсоры сеткой 2×N. |
| `editor-bottom-test111.html` | **Нижняя часть** | **Вариант B:** подвал. |
| `divtop-css-links-snippet.html` | **Верхняя часть** (фрагмент) | Только три `<link>` на global/mobile/responsive — если полный `editor-top-full` уже есть, дублировать не нужно; иначе вставить после `adaptive_kvrv.css`. |

### Вкладки, которые можно не менять

- **Правая / нижняя часть** — при варианте A, если уже стоят Telegram, VK, спонсоры и подвал.
- **Левая колонка** — не трогать; дубль «предстоящих» скрывает CSS из `kovrov-games-hub.css`.

## Настройка сезона (`seasons-config.js`)

После закачки отредактировать на сайте или локально и перезалить:

- `activeSeasonId` — id текущего сезона
- `match.gids` — номера игр из `GameDetails.aspx?gid=…`
- `match.titleContains` — подстрока в названии (например `"Made EN Russia"`)
- `reglementUrl`, `standingsUrl` — ссылки на регламент и турнирную таблицу

Игра в сезоне, если **gid в списке ИЛИ** название содержит фразу.

## Проверка после деплоя

1. Главная, полная версия (не только мобильная), Ctrl+F5.
2. Календари → полоска сезона `#kvHero` → вкладки со счётчиками → карточки.
3. F12 → Console: нет ошибок в `games-hub.js` (jQuery на EN **1.6.2** — в актуальном файле `.bind`/`.unbind`, не `.on`).
4. Старые длинные списки в центре не видны (класс `kv-legacy-hidden`).

### Частые ошибки

| Симптом | Причина | Решение |
|---------|---------|---------|
| Счётчики 0, нет карточек | Режим «Визуально» удалил `<ul id="kv-grid-…">` | Вставить `editor-main-home-FIX-test111.html` в HTML-коде |
| Старые анонсы видны | Старая `games-hub.js` или ошибка в консоли | Перезалить `games-hub.js` из репозитория |
| «Старый» вид на тесте | Не подключён `kovrov-global.css` | Вариант B, `editor-top-full-test111.html` |

| Изменили | Действие |

## Схема (вариант A)

```
[Закачка]     seasons-config.js, games-hub.js, kovrov-games-hub.css
[Верхняя часть]     → link CSS + script config + script hub
[Главная область]   → #kvHero + #kvGamesHub
[Сервер EN]         → #boxCenterActiveGames + #boxCenterComingGames (источник данных)
[games-hub.js]      → table.gameInfo → карточки → скрыть старые блоки
```

## Схема (вариант B)

```
[Закачка]     7 файлов (CSS×5 + JS×2, см. таблицу)
[Верхняя часть]     → editor-top-full-test111.html
[Главная]           → editor-main-home-FIX-test111.html
[Правая / низ]      → editor-right / editor-bottom-test111.html
```

Домены: боевой `kovrov.en.cx`, тест `kovrov-test111.en.cx` — у теста **свой** редактор дизайна; файлы на `d1.endata.cx` можно те же URL при том же аккаунте закачки.
