# Дизайн Encounter — инструкция по установке

Набор файлов для **своего поддомена** на Encounter (например `gorod.en.cx`, `test-gorod.en.cx`).  
Подходит любому городу/домену: у каждого свои ссылки, свои картинки и **свой** редактор дизайна.

Все рабочие файлы лежат **в корне этого репозитория** (на GitHub — список файлов без вложенных папок).

---

## Важно перед началом

1. **Файлы `.js` и `.css` на сайте не редактируются** в админке Encounter (там их можно только загрузить заново).  
   Порядок работы всегда один: **скачали с GitHub → поправили на компьютере → снова загрузили на сайт** (тем же именем или новым — см. ниже).

2. **HTML вставляется в редактор дизайна** домена (вкладки «Верхняя часть», «Верхняя область на главной» и т.д.). Там тоже правки делают **на компьютере** (в файлах из репозитория), потом копируют текст и вставляют в нужную вкладку.

3. **У каждого поддомена свой дизайн.** Тестовый сайт (`test-…`) и боевой (`…`) настраиваются **отдельно** — скопировать HTML с одного на другой можно, но вкладки редактора нужно заполнить для **каждого** домена.

4. В примерах ниже встречается адрес вида  
   `https://d1.endata.cx/images/personal/123456/имя_файла.css`  
   Число **`123456`** — это **ваш личный номер загрузки** (у каждого администратора свой). Его нужно подставить **везде**, где в HTML указаны ссылки на ваши файлы.

---

## Как узнать свой номер и ссылку на файл

1. Зайдите в **админку своего домена** → раздел **загрузки файлов** (картинки, CSS, JS).
2. Загрузите любой тестовый файл или откройте уже загруженный.
3. Скопируйте **полный URL** файла из браузера.  
   Пример: `https://d1.endata.cx/images/personal/987654/games-hub.js`  
   Здесь **`987654`** — ваш номер, его подставляют вместо `123456` во всех шаблонах.

После каждой перезаливки CSS/JS **имя в URL должно совпадать** с тем, что прописано в «Верхней части» сайта. Если загрузили файл с другим именем — обновите ссылку в HTML и снова сохраните вкладку редактора.

---

## Два уровня оформления — что выбрать

| | **Вариант A — только блок игр** | **Вариант B — полный новый вид** |
|---|----------------------------------|-----------------------------------|
| **Когда** | На сайте уже есть своя шапка и оформление, нужны только вкладки и карточки игр на главной | Нужен новый вид «под ключ»: шапка, меню, главная, колонка спонсоров, мобильная версия |
| **Сколько файлов залить** | 3 | 8 |
| **Какие HTML из репозитория** | `editor-top-snippet.html` + `editor-main-home-snippet.html` | `editor-top-full-test111.html`, `editor-main-home-FIX-test111.html`, `editor-right-test111.html`, `editor-bottom-test111.html` |

Имена файлов с `test111` в названии — **не привязаны к тестовому домену**, это просто старые имена шаблонов. Их можно использовать на любом поддомене.

## Пошаговая установка (первый раз)

### Шаг 1. Скачать файлы

Скачайте репозиторий с GitHub (кнопка **Code → Download ZIP**) или клонируйте через git.  
Работайте с копией на **своём компьютере** (Блокнот, Notepad++, VS Code и т.п.).

### Шаг 2. Настроить сезон (файл `seasons-config.js`)

Откройте `seasons-config.js` **на компьютере** и укажите данные **вашего** домена:

| Поле в файле | Что указать |
|--------------|-------------|
| `activeSeasonId` | Номер текущего сезона у вас на сайте |
| `match.gids` | Номера игр сезона — цифры из ссылки игры (`GameDetails.aspx?gid=**123**`) |
| `match.titleContains` | Часть названия игр сезона (если все игры содержат одну фразу) |
| `reglementUrl` | Ссылка на регламент сезона на **вашем** сайте |
| `standingsUrl` | Ссылка на турнирную таблицу на **вашем** сайте |

Сохраните файл. На сервере его **не правят** — только перезаливают после изменений.

### Шаг 3. Загрузить файлы на Encounter

В админке домена → **загрузка файлов**. Загрузите нужный набор (см. таблицы ниже).

**Вариант A — три файла:**

- `seasons-config.js`
- `games-hub.js`
- `kovrov-games-hub.css`

**Вариант B — восемь файлов:**

- все три из варианта A, плюс:
- `kovrov-global.css`
- `kovrov-mobile.css`
- `kovrov-responsive.css`
- `kovrov-inner-pages.css`
- `kovrov-team-service-record.js`

Запишите **полный URL** каждого загруженного файла (с вашим номером `personal/…`).

> В названиях есть слово `kovrov` — это историческое имя пакета, файл подходит **любому** городу. Переименовывать при загрузке не обязательно; если переименуете — не забудьте поправить ссылки в HTML.

### Шаг 4. Подставить свои ссылки в HTML-шаблоны

Откройте на компьютере нужные файлы `editor-….html` (см. таблицу «Куда вставлять»).

1. Найдите в тексте все адреса вида `https://d1.endata.cx/images/personal/…/`
2. Замените чужой номер и имена файлов на **ваши** URL из шага 3.
3. Проверьте ссылки на **логотип, звёзды, спонсоров** (вариант B) — они тоже должны вести на **ваши** загруженные картинки или на те, что уже есть у вашего домена.

Файл `divtop-css-links-snippet.html` — только три строки подключения CSS; нужен, если вы **дописываете** стили к уже существующей шапке, а не вставляете целиком `editor-top-full-test111.html`.

### Шаг 5. Вставить HTML в редактор дизайна

Админка домена → **редактор дизайна**. Обычно четыре вкладки:

| Вкладка в админке Encounter | Файл из репозитория (вариант A) | Файл (вариант B) |
|-----------------------------|--------------------------------|------------------|
| **Верхняя часть** | `editor-top-snippet.html` (в **конец**, не удаляя то, что уже было) | `editor-top-full-test111.html` |
| **Верхняя область на главной** | `editor-main-home-snippet.html` | `editor-main-home-FIX-test111.html` |
| **Правая часть** | можно не менять | `editor-right-test111.html` |
| **Нижняя часть** | можно не менять | `editor-bottom-test111.html` |

**Обязательно включите режим «HTML код»** (не «Визуально»).  
В визуальном режиме редактор часто **удаляет пустые списки** — тогда на главной пропадают карточки игр (счётчики остаются нулями).

Скопируйте **весь** текст из подготовленного файла → вставьте в вкладку → **Сохранить**.

### Шаг 6. Проверить главную страницу

1. Откройте главную сайта в браузере на компьютере (лучше полная версия, не только телефон).
2. Нажмите **Ctrl+F5** (жёсткое обновление, чтобы подтянулись новые CSS/JS).
3. Должны появиться: полоска сезона, вкладки («Идут сейчас», «Сезон» и др.), карточки игр.
4. Старые длинные списки игр по центру должны **исчезнуть** (их заменяет новый блок).

Если карточек нет — см. раздел «Если что-то пошло не так» внизу.

## Справочник: файлы для загрузки на сайт

Эти файлы **не вставляются в редактор** — их только **загружают** в раздел файлов домена. Подключение к странице происходит через ссылки в «Верхней части» (из HTML-шаблонов).

| Файл | Простыми словами | Когда нужен |
|------|------------------|-------------|
| `seasons-config.js` | Настройки сезона: какие игры считать сезонными, ссылки на регламент и таблицу | Всегда (A и B) |
| `games-hub.js` | Собирает игры со страницы и рисует вкладки и карточки на главной | Всегда (A и B) |
| `kovrov-games-hub.css` | Внешний вид блока игр и календарей; прячет лишний блок «предстоящих» слева | Всегда (A и B) |
| `kovrov-global.css` | Общий вид сайта: фон, шапка, меню, колонки | Только вариант B |
| `kovrov-mobile.css` | Доп. правки для телефонов | Только вариант B |
| `kovrov-responsive.css` | Чтобы внутренние страницы (FAQ, регламенты) нормально смотрелись на узком экране | Только вариант B |
| `kovrov-inner-pages.css` | Оформление почты, страниц команды и игрока | Только вариант B |
| `kovrov-team-service-record.js` | Удобный вид «послужного списка» на странице команды | Только вариант B |

**Порядок подключения в «Верхней части»** (если собираете ссылки вручную, вариант B):

1. Сначала ваши старые стили домена (если были).
2. `kovrov-games-hub.css`
3. `kovrov-global.css`
4. `kovrov-mobile.css`
5. `kovrov-responsive.css`
6. `kovrov-inner-pages.css`
7. Потом скрипты: `seasons-config.js` → `games-hub.js` → `kovrov-team-service-record.js` (последний только для B).

Скрипты должны идти **после** jQuery (на Encounter она уже есть на странице — обычно ничего дополнительно подключать не нужно).

## Справочник: файлы для редактора дизайна

Это **текстовые шаблоны**. Их открывают на компьютере, подставляют **свои** URL, копируют в нужную вкладку редактора.

| Файл | Куда вставить в админке | Что делает |
|------|-------------------------|------------|
| `editor-top-snippet.html` | Верхняя часть (в конец) | Вариант A: три строки — подключить CSS и два скрипта игр |
| `editor-main-home-snippet.html` | Верхняя область на главной | Вариант A: блок сезона и вкладки с играми |
| `editor-top-full-test111.html` | Верхняя часть | Вариант B: шапка, меню, стили и скрипты целиком |
| `editor-main-home-FIX-test111.html` | Верхняя область на главной | Вариант B: разметка главной под карточки |
| `editor-right-test111.html` | Правая часть | Вариант B: соцсети и спонсоры (картинки — **ваши** ссылки) |
| `editor-bottom-test111.html` | Нижняя часть | Вариант B: подвал |
| `divtop-css-links-snippet.html` | Фрагмент в верхнюю часть | Только три CSS из варианта B, если шапку не меняете целиком |

### Что на главной трогать нельзя

На главной странице Encounter **должны остаться** стандартные блоки со списками игр (те, что сайт рисует сам). Скрипт `games-hub.js` **читает** их и потом **скрывает**, показывая вместо них новые карточки. Если эти блоки удалить из HTML — карточки не появятся.

Календари домена, если они у вас есть, обычно оставляют там, где они были; блок игр можно разместить выше или ниже — по желанию оформителя.

## Как обновлять после правок

| Что изменили | Где править | Что сделать на сайте |
|--------------|-------------|----------------------|
| Сезон, список игр, ссылки регламента | `seasons-config.js` на компьютере | Перезалить файл → Ctrl+F5 |
| Внешний вид карточек и вкладок | `kovrov-games-hub.css` | Перезалить → Ctrl+F5 |
| Общий вид сайта, шапка, меню | `kovrov-global.css` (+ при необходимости mobile / responsive / inner) | Перезалить → Ctrl+F5 |
| Логика вкладок, отбор игр | `games-hub.js` | Перезалить → Ctrl+F5 |
| Текст/разметка шапки, главной, колонок | соответствующий `editor-….html` | Подставить URL → скопировать в вкладку редактора → Сохранить |
| Спонсоры, подвал | `editor-right-test111.html` / `editor-bottom-test111.html` | То же |

**Повтор:** в админке Encounter **нет** нормального редактора для `.js` / `.css` — только загрузка новой версии файла.

## Если что-то пошло не так

| Что видите | Вероятная причина | Что сделать |
|------------|-------------------|-------------|
| Вкладки есть, везде «0», карточек нет | Вставляли главную в режиме «Визуально» | Открыть вкладку «Верхняя область на главной» → режим **HTML код** → вставить заново из `editor-main-home-snippet.html` или `editor-main-home-FIX-test111.html` |
| Старые длинные списки игр всё ещё видны | Не подключился `games-hub.js` или в консоли ошибка | Проверить URL скрипта в «Верхней части», перезалить актуальный `games-hub.js` с GitHub |
| Сайт «как раньше», без новой шапки | Вариант B, но не вставлен `editor-top-full-test111.html` или не залит `kovrov-global.css` | Пройти шаги варианта B заново |
| Стили не обновились | Кэш браузера | Ctrl+F5; при необходимости зайти в режиме инкогнито |
| Красные ошибки в консоли (F12) | Неверная ссылка на файл или старая версия скрипта | F12 → вкладка Console → проверить, какой адрес «не найден»; исправить в HTML или перезалить файл |

**Как открыть консоль:** в Chrome / Edge нажмите **F12** → вкладка **Console** (Консоль). Красные строки — подсказка, какой файл не загрузился.

## Краткая схема работы

```
GitHub (файлы на компьютере)
        │
        ├─► .js / .css  ──► загрузка в админке домена ──► скопировать URL
        │
        └─► editor-….html ──► подставить свои URL ──► редактор дизайна (HTML код)

Главная страница сайта: стандартные списки игр ──► games-hub.js ──► новые карточки
```

## Вопросы по нескольким доменам

- **Тест и бой** — два разных поддомена → два раза настроить редактор и (при необходимости) два раза залить файлы.
- **Один аккаунт загрузки** — URL файлов на `d1.endata.cx` могут быть **одинаковыми** на тесте и на бою; HTML во вкладках всё равно нужно сохранить **в каждом** домене отдельно.
- **Разные администраторы** — у каждого свой номер в `personal/…`; в HTML всегда должны быть **их** ссылки.

Если нужна помощь с настройкой под конкретный город — сохраните скриншот главной и вкладки «Верхняя часть» (режим HTML) и укажите адрес вашего поддомена.
