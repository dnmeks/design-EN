# design-EN

Дизайн и деплой для сайтов Encounter (kovrov): прототип, CSS/JS для редактора дизайна и пошаговые инструкции.

## Структура

| Папка / файл | Описание |
|--------------|----------|
| `deploy/` | Файлы для закачки на Encounter и сниппеты для вкладок редактора |
| `prototype/` | Локальный прототип главной (HTML/CSS/JS) |
| `deploy/ИНСТРУКЦИЯ-ДЕПЛОЙ.md` | Деплой на боевой домен |
| `deploy/ИНСТРУКЦИЯ-ТЕСТ-test111.md` | Деплой на тестовый домен test111 |

## Быстрый старт

1. Откройте `deploy/ИНСТРУКЦИЯ-ДЕПЛОЙ.md` или `deploy/ИНСТРУКЦИЯ-ТЕСТ-test111.md`.
2. Закачайте `seasons-config.js`, `games-hub.js`, CSS согласно инструкции.
3. Вставьте сниппеты из `deploy/editor-*.html` в соответствующие вкладки редактора дизайна.
