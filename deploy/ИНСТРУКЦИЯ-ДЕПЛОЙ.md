# Пошаговый деплой нового блока игр на kovrov.en.cx

**Тестовый домен:** [https://kovrov-test111.en.cx/](https://kovrov-test111.en.cx/) — те же шаги, но правки делаются в **редакторе дизайна этого домена** (у теста свой дизайн, не копируется с боевого автоматически). Файлы на `d1.endata.cx` можно использовать те же URL, если закачиваете с того же аккаунта.

У вас есть только **редактор дизайна** (4 вкладки) и **закачка файлов**. Штатные блоки игр (`#boxCenterActiveGames`, `#boxCenterComingGames`) остаются на странице — скрипт их читает и скрывает после отрисовки карточек.

---

## Шаг 0. Файлы в папке `deploy/`

| Файл | Назначение |
|------|------------|
| `seasons-config.js` | Какие игры считать «сезонными» (gid + фраза в названии) |
| `games-hub.js` | Парсит таблицы игр, рисует вкладки и карточки |
| `kovrov-games-hub.css` | Стили блока + скрытие `#boxComingGames` и старых списков |
| `editor-top-snippet.html` | Что вставить во **«Верхнюю часть»** |
| `editor-main-home-snippet.html` | Что вставить в **«Верхнюю область на главной»** |

---

## Шаг 1. Закачать 3 файла на Encounter

1. Админка домена → **закачка файла** (картинки / CSS / JS).
2. Загрузите по очереди:
   - `seasons-config.js`
   - `games-hub.js`
   - `kovrov-games-hub.css`
3. После загрузки откройте каждый файл в списке и **скопируйте URL**.  
   Обычно он такой:  
   `https://d1.endata.cx/images/personal/ВАШ_ID/имя_файла.js`

На сайте уже используется ID **144762** — если закачиваете под тем же аккаунтом, пути из примеров подойдут. Если ID другой — замените `144762` везде в сниппетах.

---

## Шаг 2. Настроить сезон (один раз и при смене сезона)

Откройте закачанный `seasons-config.js` в редакторе файлов на сайте (или отредактируйте локально и перезалейте):

- `activeSeasonId` — id текущего сезона в конфиге
- `match.gids` — номера игр (gid из ссылки `GameDetails.aspx?gid=…`)
- `match.titleContains` — подстрока в названии (например `"Made EN Russia"`)
- `reglementUrl`, `standingsUrl` — ссылки на регламент и таблицу

Логика: игра в сезоне, если **gid в списке ИЛИ** название содержит фразу.

---

## Шаг 3. Вкладка «Верхняя часть»

**Не удаляйте** то, что уже есть (шапка `dnk_head`, `kovrov_css.css`, адаптив, онлайн-стили и т.д.).

В **конец** блока (режим **HTML код**) вставьте содержимое файла `editor-top-snippet.html`, подставив свои URL, если ID не 144762:

```html
<link rel="stylesheet" type="text/css" href="https://d1.endata.cx/images/personal/144762/kovrov-games-hub.css" />
<script type="text/javascript" src="https://d1.endata.cx/images/personal/144762/seasons-config.js"></script>
<script type="text/javascript" src="https://d1.endata.cx/images/personal/144762/games-hub.js"></script>
```

Порядок важен: сначала CSS, потом `seasons-config.js`, потом `games-hub.js` (jQuery на сайте уже есть).

Сохраните.

---

## Шаг 4. Вкладка «Верхняя область на главной»

1. **Календари не трогать** — блоки с `#divCalendar`, `#divCalendar2` и их скриптами должны остаться в **центральном контенте** (`boxCenterContent`), как сейчас.
2. В эту вкладку вставьте содержимое `editor-main-home-snippet.html` — блоки `#kvHero` и `#kvGamesHub` с пустыми списками `<ul id="kv-grid-…">`.  
   Скрипт заполнит их сам при загрузке главной.

Если редактор вставляет разметку **над** календарями, а вы хотите календари сверху — перенесите HTML хаба ниже календарей вручную или оставьте календари только в `boxCenterContent`, а в «Верхней области на главной» — только хаб.

Сохраните.

---

## Шаг 5. Вкладки «Правая часть» и «Нижняя часть»

**Ничего менять не обязательно**, если там уже `DivRightDesign` (Telegram, VK, спонсоры) и подвал. Новый дизайн игр их не затрагивает.

---

## Шаг 6. Левая колонка

Скрытие дубля «предстоящих» в левой колонке делает CSS:

```css
#boxComingGames { display: none !important; }
```

Он уже в `kovrov-games-hub.css`. ЛК (`#boxUser`), орг-панель и `#boxOnlineHelp` **не скрываются**.

## Частые ошибки (test111)

1. **Режим «Визуально»** — редактор удалил все `<ul id="kv-grid-…">`. Счётчики 0, карточек нет. Решение: вставить HTML из `editor-main-home-FIX-test111.html` в режиме **HTML код**.
2. **Синтаксическая ошибка в games-hub.js** — старая версия ломала весь скрипт. Перезалейте актуальный `games-hub.js` из папки `deploy/`.
3. **`.on` / `.off` в консоли** — на Encounter jQuery **1.6.2**, там нет этих методов. В актуальном `games-hub.js` используется `.bind` / `.unbind`. Без этого карточки рисуются, но старые анонсы не скрываются.
4. **Дизайн «старый»** — на тестовом домене нет полной шапки kovrov; новый блок — только зелёные панели `#kvHero` / `#kvGamesHub` после подключения CSS.
5. После правок: Ctrl+F5, F12 → Console — не должно быть красных ошибок на `games-hub.js`.

## Шаг 7. Проверка на главной

1. Откройте тест: `https://kovrov-test111.en.cx/` (или бой: `https://kovrov.en.cx/`) — полная версия, не мобильная.
2. Должны быть: ваши календари → полоска сезона (`#kvHero`) → вкладки с счётчиками → карточки игр.
3. Вкладка **«Идут сейчас»** — только игры с кнопкой «Вход в игру».
4. **«Виртуальные»** — МШ (zone 1) и викторина (zone 9).
5. Старые длинные списки в центре не видны (скрыты классом `kv-legacy-hidden`), но в исходном коде страницы остаются — так задумано.

Если карточек нет: F12 → Console — ошибки загрузки JS/CSS или отсутствие `#kvGamesHub` / блоков игр.

## Что не делать

- Не удалять `#boxCenterActiveGames` и `#boxCenterComingGames` с главной.
- Не ломать `ul.menu` / `menuWrap` — меню под шапкой остаётся штатным.
- Не подключать `games-hub.js` **до** jQuery (оставьте в «Верхней части» после стандартных скриптов страницы).

## Обновление после правок

| Изменили | Действие |
|----------|----------|
| Стили | Перезалить `kovrov-games-hub.css`, обновить страницу Ctrl+F5 |
| Логику вкладок / парсинг | Перезалить `games-hub.js` |
| Состав сезона | Править `seasons-config.js` |
| Разметку вкладок | Редактор → «Верхняя область на главной» |

---

## Краткая схема

```
[Верхняя часть]     → CSS + seasons-config.js + games-hub.js
[Главная область]   → #kvHero + #kvGamesHub (пустые сетки)
[Сервер EN]         → #boxCenterActiveGames + #boxCenterComingGames (источник данных)
[games-hub.js]      → читает table.gameInfo → рисует карточки → скрывает старые блоки
```
